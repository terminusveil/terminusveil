# Security

Terminus Veil is a read-only desk. It holds no funds, no keys and no wallet connection; the only state it keeps is a covering in your browser.

If you find something wrong, on the site, in the public reads under `/api/`, or in `contracts/`, write to [@terminus_veil](https://x.com/terminus_veil) on X. Say what you found and how to reproduce it. We answer there.

`/.well-known/security.txt` carries the same contact.
